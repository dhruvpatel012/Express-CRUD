# Node.js CRUD API

A simple CRUD API project built using Node.js, Express.js, and the File System (`fs`) module. Product data is stored in a `db.json` file.

## Features

- **GET /** – Displays a welcome message.
- **GET /products** – Retrieves all products.
- **POST /add** – Adds a new product.
- **DELETE /deleteproduct/:id** – Deletes a product by ID.

**Note:** The project currently implements Create, Read, and Delete operations. Update is not implemented yet.

## Technologies Used

- Node.js
- Express.js
- File System (`fs`)
- JSON

## Installation and Setup

1. Clone or download this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   npm run server
   ```

4. Open `http://localhost:1212` in your browser.
